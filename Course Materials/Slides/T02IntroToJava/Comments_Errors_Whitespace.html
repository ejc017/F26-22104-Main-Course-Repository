Alignment of Code Has No Impact on Execution and a Large Impact on Readability

  • Code alignment (indentation) has no impact on the execution of your code.

    Code Alignment

  • Code alignment should be considered for readability of your code.
  • Blocks of code that execute within separate blocks of code should be indented to indicate the hierarchical relationship between the code blocks.
    • This will be more clear when we study loops.
    • You have already seen this alignment concept with the presentation of the the class definition and the main method that exists within the class on lines 1 and 2.

Comments Written in Java Class Files are Not Executed

  • It is often useful to write comments inside your code.
    • Explain what code is doing
    • Organize code with section headings
    • Add ToDo remarks to yourself
  • There are two types of comments
    • Single-line comments excecuted with the following two forward slashes (//)
    • Multi-line comments begin with /* and end with */
    // This single line is a comment
    /* 
    First line of multi-line comment
    Second line of multi-line comment
    */

You Will Experience Programming Errors (Often)…Learn What They are Telling You

  • There are multiple types of errors you will experience in Java
    • Syntax errors
      • Errors that prevent the code from compiling
      • Errors typically indicated by red squiggly line in IntelliJ
    • Logic errors
      • Errors caused by a flaw in your code implementation
      • Code may run to completion with a logic error (output will just be wrong)
    • Runtime errors
      • Code compiles, but terminates pre-maturely during execution when the code is asked to do something not allowed by Java
